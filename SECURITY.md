## Reporting a Vulnerability

If you discover a security vulnerability in SecretShield, please report
it via GitHub's private security disclosure feature:

  https://github.com/SKKammar/SecretShield/security/advisories/new

Do not open a public issue for security vulnerabilities.
We will respond within 72 hours and coordinate a fix and disclosure.

## Scope
- Bypasses to secret detection (false negatives on known patterns)
- Information disclosure in scan reports or PR comments
- Vulnerabilities in the dashboard PAT handling
